# S.P.A.R.K.-AI
S.P.A.R.K. is an AI tutor for Class 11-12 PCM students (Physics, Chemistry, Maths). It’s a single-file HTML app with a sci-fi HUD interface, Gemini & Gemma support, Word/PDF export of answers, and a Cloudflare Worker backend so students never need an API key.

To install S.P.A.R.K.-AI, scroll down and find the releases section on the right hand side column. click on "S.P.A.R.K.-AI v1."
followed by a click on "Source code (zip) to download the zip file.

***FOR WINDOWS*** ---> double-click SPARK.bat (after extracting the files)

***FOR ANDROID*** ---> open index.html (after extracting the files)

***FOR LINUX*** ---> run "./SPARK.command" in a terminal (after extracting the files)

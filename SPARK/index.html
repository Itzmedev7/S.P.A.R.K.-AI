Before you start

S.P.A.R.K. is free because it runs through the developer’s server. Your questions and Spark’s answers are saved there, and the developer can read them to fix problems and improve the app. They are also processed by Google Gemini.

Photos you attach are not saved. Please don’t type passwords or private details. Saved chats are deleted automatically after 90 days, and you can delete yours any time in Settings → Delete my saved chats.

Settings

Free limits are per Google project and change over time. Check the current numbers in Google AI Studio under Rate limits.

Free key, no card needed: open aistudio.google.com, sign in with Google, click Get API key then Create API key. The same key works with any Gemini model. Flash gives the best answers but has few free requests per day; Flash-Lite models allow many more. If a model name errors, check the list in AI Studio.

Get a key at platform.openai.com/api-keys. It is stored only in this browser on this device and sent only to OpenAI. This is a paid key — set a usage limit in your OpenAI billing settings.

Your chats are saved on the developer’s server so problems can be fixed. You can remove them at any time.

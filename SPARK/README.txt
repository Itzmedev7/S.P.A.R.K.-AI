S.P.A.R.K. AI - run it on localhost
===================================
Unzip the whole folder first (do not run from inside the zip), then:

WINDOWS   Double-click SPARK.bat (nothing to install).
MAC       Double-click SPARK.command. First time: right-click > Open > Open.
LINUX     Terminal: chmod +x SPARK.command && ./SPARK.command
ANDROID   Install Termux, then: pkg install python
          In the SPARK folder run: sh SPARK.command
          Chrome menu > Add to Home screen installs it as an app.
IPHONE    iOS cannot run a local server. Host this folder online
          (GitHub Pages), open the link in Safari > Share > Add to Home Screen.

It opens at http://localhost:8080 (next free port if busy).
Keep index.html, sw.js, manifest.webmanifest and the icons folder together.
